# Modelo 3D do velocímetro

`B737_nologo.glb` é disponibilizado pelo projeto [amvlab/aircraft-models](https://github.com/amvlab/aircraft-models), na variante sem logótipo.

O modelo e as imagens do projeto original estão sob a licença [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). Foi incorporado no DriverWise sem alterações de geometria; o tamanho é aproximadamente 174 KB. A animação, a pista e os efeitos são implementados pelo DriverWise.
